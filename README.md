### 🩺 env-doctor
The **eslint of environment variables**. Catches missing/undocumented env vars before they hit production. Ships as:
- CLI tool for local development
- VS Code Extension with inline warnings
- GitHub Action for PR checks

### ⚡ llm-gateway
Multi-provider LLM routing gateway. The plumbing behind a real GenAI backend. Handles:
- Provider fallback — auto-switch on failure
- Response caching — save tokens & latency
- Rate limiting — protect your budget
- Cost tracking — monitor spend per request
